Sortir l'export Stripe d'un client

Projet arrêté le 16 octobre 2026 : cette page reste en ligne comme documentation, aucun envoi n'est traité.

Deux fichiers CSV sur le même mois, depuis le tableau de bord Stripe du client. Le client peut les sortir lui-même, ou vous les envoyer si vous avez un accès en lecture.

1. L'activité du solde

Rapports > Solde > Balance change from activity, puis Télécharger, format Itemized.

Dans « Colonnes », ajoutez si possible source_id, customer_facing_amount, customer_facing_currency et automatic_payout_id. Sans elles, le fichier sort quand même, mais le lettrage des remboursements et des litiges est moins précis, et le rapport le signale.

2. Les virements

Rapports > Solde > Payouts, puis Télécharger, format Itemized. Ce rapport contient les virements vers la banque, absents du premier.

Fuseau horaire

Choisissez Europe/Paris. Sinon, une vente de 23 h 30 le 30 tombe le 1er du mois suivant.

Données personnelles

Vous pouvez vider la colonne description  : seuls les montants, les dates et les catégories Stripe servent au calcul.

Importer le FEC reçu

  • ACD : Outils > Importation > Importation FEC, avec « Rupture par pièce ».
  • Cegid Loop : import FEC ; le lettrage est repris.
  • MyUnisoft : Imports > Import FEC, sur l'exercice concerné.
  • Sage : import FEC sur un exercice ouvert, journaux créés au préalable.
  • Quadra, Isacompta, Inqom : import FEC standard, validé avec vous au premier dossier.

Importez chaque fichier une seule fois : la plupart des logiciels ajoutent les écritures en double si on réimporte.
